# 第四版建模说明

## 改进与可行性

第三版仅尝试两档固定粒度，部分图的独立工作被放在同一子图内。第四版扩大粒度搜索，并保留第三版最优方案。它是可复现启发式与离散参数搜索，不是全局最优算法。

COPY 收缩后的 DAG 为 G=(V,E)。使用编号最小优先的拓扑排序得到 v₁,…,vₙ。块大小为 q 时，vᵢ 属于 floor((i−1)/q) 块。每块是拓扑序连续区间，跨块依赖只从较小块号指向较大块号，保证商图无环。各核块序列也保持编号递增；最终仍需官方模拟检查执行约束。

分核沿用第三版的预计完成时间贪心规则：每块试放到各核，结合核心空闲时刻、前驱预计完成时刻和块内工作量代理选择核心。同步常数沿用 A 场景，对 B/L2 也只作为生成候选的代理，真实等待与通信由对应官方评估处理。本版新增贡献是扩大粒度搜索，未重新实现官方模拟器。

## 搜索预算

非 COPY 操作数不超过 5000 时，q∈{1,2,4,8,16,24,48,96,192,384,768}。更大时先评估 {4,16,48,192,768}，按当前场景成绩最好的粗粒度做一次细搜：

| 粗搜最优 q | 追加 q |
|---:|---|
| 4 | 1,2,8 |
| 16 | 8,24,32 |
| 48 | 24,32,96 |
| 192 | 96,128,384 |
| 768 | 384,512,1536 |

不会迭代至局部最优。题一、题二分别按 `(官方 Makespan, 新增 COPY 字节数)` 字典序选择，并保留第三版最优方案，故最终成绩不会退步。

题三固定新的题二方案，把其 B 结果与官方模拟的 L2 结果配对；另将题二已成功评估候选中成绩最好的至多三个送入 L2 模拟，同时保留第三版 L2 最优。并未穷举 L2 全部粒度。方案重复会去重，候选错误会记录，最终成绩只取成功候选。

## 指标与下界

单核归一化加速比 S=T_single/T_selected；版本改进比 R=T_v3/T_v4。均先逐组求比再取算术平均。平均耗时下降单独计算 mean(1−T_v4/T_v3)，不能对 mean(R) 取倒数换算。题三 Cache 收益用固定题二方案的无 L2/有 L2 比值，不与题三换方案收益混淆。

计算下界 LB=max(非 COPY 最长计算链, max_p Pipe 总计算工作量_p/K)。忽略数据搬运、内存和等待，故只作必要下界。T/LB 接近 1 表明剩余空间有限；T/LB 较大不单独证明算法差，也可能来自忽略的资源约束。

## 局限与复现

正式实验须覆盖 100 个实例、2～5 核、三问共 1200 份方案，同时报告严格改善数、中位数与平均值。此处是在公开实例上直接选优，不是独立测试集的泛化验证。编号并列优先级对节点重新编号不具有不变性。

本版只改变粒度，不改变调度优先级、不做跨核移动。候选数量增加带来求解器耗时增加；模拟 cycles 降低不等于求解器运行更快。整体复杂度还包含图收缩、堆排序、K 核试放和多次官方模拟，不能称为严格线性。

第三版最终指标、方案和单核基准直接复用，记录来源与哈希；第四版静态完整性校验、全部方案官方合法性检查、分层选取方案的独立重新模拟应分别报告，不能笼统称为全部官方复跑。

## 已发现的低加速根因实例

在五核问题二中，第三版 case_016 的 17995 个非 COPY 操作全部分在一个核，另四核为空；第四版分布为 [4116,4115,3358,3355,3051]。case_024 的 5959 个操作在第三版也全部位于一个核；第四版分布为 [1362,1361,1114,1111,1011]。这些是操作数量分布，不等于各核计算周期或利用率。

两例第四版均选中每块一个操作的细粒度方案。在 B 场景，同核子图会合并成 Task，细粒度提供更自由的分核选择，不会像 A 场景那样使每个小块都独立承担 Task 切换开销。因此可以解释 B 的明显改善，但不能把“越细越好”推广到 A 或全部图。
